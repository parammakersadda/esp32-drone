# ESP32 Drone Controller Prototype

Experimental ESP32-based drone controller firmware using the MPU6050 IMU sensor.

## About

This project is a personal prototype flight-control experiment based on an ESP32 microcontroller and MPU6050 IMU. It is shared as a reference for learning, experimentation, and further development.

## Safety Notes

- Test with propellers removed whenever possible.
- Verify motor direction, control response, and failsafe behavior before attempting flight.
- Use appropriate safety precautions during all testing.
- This project is intended for experimentation and educational purposes, not commercial, certified, or safety-critical applications.
